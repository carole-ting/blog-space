Hello Hexo!

今天是個特別的日子，我正式用 Hexo 寫下人生第一篇部落格文章。
從安裝、建立，到第一次輸出畫面，過程其實比我想像中簡單(還是有點小複雜…)，重點是還蠻有成就感的！

為什麼是 Hexo？

  • 速度快：文章用 Markdown 寫，生成網頁一瞬間。
  • 主題多：隨便換個 theme，就能讓網站長得超專業。
  • 部署方便：丟到 GitHub Pages、Netlify 都沒問題。

接下來要寫什麼？

我希望在這裡記錄：

  • 我的學習筆記
  • 一些技術紀錄（可能會有程式碼）
  • 生活隨筆（偶爾閒聊）

小結

部落格的第一步已經完成啦！
希望未來這裡能慢慢長成一個屬於自己的知識與故事小天地。

謝謝 Hexo，讓我踏出這一步 🎉
